Smart Flood Alert: IoT water telemetry pipeline

IoT early warning hardware and cloud telemetry platform detecting urban flash floods.

Role Full Stack IoT and Backend Engineer
Core technologies ESP32 (C++), FC-28 sensor, Python FastAPI
Status Deployed and open source
Repository GitHub repository

1. Project introduction

Monsoon rains cause flash flooding in underpasses and low-lying sectors within minutes. Traditional municipal monitoring systems are sparse, leaving commuters vulnerable during sudden cloudbursts.

Smart Flood Alert couples a low-cost sensing node with a telemetry backend delivering warnings over WhatsApp, the primary communication channel in India.

2. Problems addressed

Disaster dispatches often suffer from 30 to 60 minute broadcast latency. Submersible sensors degrade quickly from silt and corrosion. Standalone apps have high install friction.

3. System design objectives

Target alert propagation is under 5 seconds from edge sensor detection to smartphone notification. The system evaluates three discrete states: Nominal (under 40mm), Warning (40 to 70mm), and Critical (over 70mm).

4. Technical architecture

The architecture comprises three synchronized tiers:

Edge sensing: An ESP32 microcontroller with an FC-28 resistive moisture probe samples ADC pins at 10Hz, applies a moving median filter to eliminate wave noise, and transmits HTTP POST telemetry.

FastAPI gateway: High-throughput Python service receiving JSON telemetry payloads, validating cryptographic tokens, and evaluating alert thresholds.

Meta WhatsApp dispatch: Emergency evacuation alerts dispatched when water exceeds critical thresholds for more than 3 consecutive samples.

5. Challenges and solutions

Challenge: False positives from splashing

Passing vehicles caused brief voltage spikes on sensor pins.

Solution: Implemented temporal debounce on the ESP32 requiring 10 consecutive readings above threshold over a 4-second continuous window.

Challenge: Notification throttling

Sustained critical flood conditions risked triggering excessive WhatsApp messages.

Solution: Built dynamic backoff in FastAPI sending an urgent broadcast followed by hourly delta status digests.

6. Current status and repository

Firmware in C++, cloud backend in FastAPI, and the web dashboard are open-sourced under the MIT license.
