AlbumCanvas: Android ambient media engine

Dynamic live wallpaper and widget engine extracting palettes from Android playback sessions.

Role Android Systems Engineer
Core technologies Kotlin, Jetpack Compose, Media3
Status Released and open source
Repository GitHub repository

1. Project overview

AlbumCanvas dynamically transforms device home and lock screens into ambient living surfaces synchronized with currently playing music across Spotify, YouTube Music, and Apple Music.

The application hooks Android NotificationListenerService and MediaSessionManager to extract artwork, cluster dynamic colors, and drive GPU shaders.

2. System architecture

The engine separates media extraction, image color quantization, and rendering into isolated pipelines:

MediaSession listener: Intercepts metadata change events across all active media players without requiring vendor-specific SDK integrations.

Palette clustering: AndroidX Palette quantizes bitmap pixels into vibrant and muted swatches on every track transition.

Hardware rendering: Custom WallpaperService utilizing Android 12 RenderEffect shaders for 60fps blur with zero idle battery consumption.

Interactive media simulator

Test the live web simulator with track transitions, color quantization, and glassmorphic widget controls.

3. Engineering challenges

Challenge: Battery drain from continuous rendering

Live wallpapers frequently suffer from aggressive CPU wake-locks and battery exhaustion.

Solution: Implemented hardware RenderEffect shaders with sleep state triggers when playback pauses or screen turns off.

Challenge: Asynchronous bitmap acquisition

Media players push artwork asynchronously, creating race conditions during rapid track scrubbing.

Solution: Built Kotlin StateFlow debouncers ensuring only the latest stable bitmap triggers palette computation.

4. Open source availability

Complete Kotlin source code, Jetpack Compose layouts, and Gradle configurations are available under the MIT license.
